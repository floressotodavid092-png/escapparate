Escaparate - Rapport CRM template (visual demo)

1) Extract this folder.
2) Open terminal in this folder (the folder containing docker-compose.yml).
3) Start Docker:
   docker compose up -d
4) Open in your browser:
   http://localhost:8080

Stop:
   docker compose down

The demo is static and uses sample data only. It is not connected to Supabase,
backend APIs, or the existing login/register implementation.
